# 品牌与设计规范

## 品牌与视觉

品牌为 Joya Mana，Logo、字标、字体授权、正式颜色和真实商品摄影/视频已确认。
只用获批资产。设计方向是现代、克制、温暖，关注自然纹理和日常佩戴；不据此编造
商品功效或价值承诺。声明限制见 [内容与索引](CONTENT_SEO_GEO_SPEC.md#内容模型与审核)。

品牌/客服配置见 [brand.ts](../src/config/brand.ts)，颜色、尺寸和留白统一以
[globals.css](../src/app/globals.css) 为准。米白为主背景，理念区浅奶白，浅紫表示选中，
深棕用于操作和细节，花卉色辅助。文字、状态和错误色与装饰色分开。

资源在 [public/brand](../public/brand/)，来自获批 `【最终】joya mana logo.ai`。
保留原稿图形路径；字标将内嵌朱雀仿宋字形转为轮廓，保持字距和比例，裁去画板留白。
不通过网页字体重排字标，不拉伸、重绘或添加未经确认的寓意。

[BrandLogo](../src/components/brand-logo.tsx)集中管理版本与稳定图片尺寸。
已有 aria-label 的品牌链接用空 alt，其他品牌展示读作 Joya Mana；装饰图不重复朗读。
图标保留原轮廓，发布检查 16/32px 和手机收藏显示；小尺寸简化版须另行确认。

[繁中 layout](../src/app/zh-hant-us/layout.tsx)，加载与授权见技术规格。

主按钮深棕底白字，次按钮用深棕边框；焦点清晰，深色背景有隔离环。
选款和筛选同时提供文字/勾选/pressed 状态。导航 hover 不淡化文字，Footer 保留下划线。
不可购买卡片可褪色并显示状态，商品详情原图保持原色。

## 导航与页面

Header 保留 Shop All 和非空类别。非空设计系列：0 个隐藏，1–2 个直接列名，
3 个以上用 Collections 下拉和 View All；桌面与手机共用数据，类别与系列分开。
New 入口须有至少 4–6 个近期商品和稳定上新后再评估。

桌面工具依次 Search、Language、Bag；手机图标有可读名称。英语用 Bag/Add to bag，
繁中用購物袋，路径仍 `/cart`。语言显示当前开放选项，不用国旗；切语言保留当前页面
和允许的款式/筛选参数。Footer 显示 US，不提供未启用的地区或币种选项。

桌面下拉支持键盘、Escape、焦点离开、遮罩和 hover。手机菜单使用原生 dialog，锁定
背景和滚动，Tab 留在菜单；关闭/Escape 后回到按钮，切到桌面时焦点落在可见链接。
目录分组用 accordion。

首页采用 [手链静物编辑背景](../public/images/joya-mana-home-hero-still-life.webp)，以 Shopify
当前 Golden Citrine Bracelet — 12 mm 的[真实商品照片](https://cdn.shopify.com/s/files/1/1013/9661/1381/files/BB-NN-CIC-C-YW-120-M-C-NA-00001-01_c792285c-ba49-4491-b4ff-2db7243c7ce5.jpg?v=1787295240)
为参考，石面、光线与整体静物构图为生成的品牌编辑视觉。该图不作为交付商品的实物照片，
不声称真实拍摄地点、产地或工艺，也不表示原商品细节经过像素级保留；商品卡与 PDP
继续使用 Shopify 原始商品摄影。

桌面/平板首页使用连续浅色背景，左侧文案、右侧静物；手机使用
[竖版构图](../public/images/joya-mana-home-hero-still-life-mobile.webp)，文案和操作居中，
手链完整，避免文字覆盖商品，次入口用文字链接。商品卡和详情始终使用 Shopify 摄影。
精选区直接显示标题与介绍，无可售候选时提供准确空态；不加 Blog 推荐或系列条带。
理念区保留已确认文案，桌面双列，手机依次标题、介绍/三条理念、故事链接。

Footer 直接衔接内容，不加纹样带；手机品牌居中，Explore/Customer Care 两列，法律
链接为有名称的辅助导航。地区和语言并排，当前语言有标记，版权在末行。
Blog 与 Crystal Guide 列表使用独立的紧凑布局，详情与 About 使用下述阅读宽度；
其他内容区沿用商品区的宽度和留白。

这两个列表共用最大约 1120px 的内容容器和左对齐小页头；手机两侧留白约 20px。
Blog 为统一单列文字列表，无独立 Featured；Crystal Guide 大于 640px 为双列，
640px 及以下为单列，无编号和图片。标题完整显示，摘要最多两行，每条只有一个详情
链接，以标题作为可读链接名称，整条可点击且焦点可见。首屏内容自然出现，不用固定
展示高度撑高页头、条目或空态。

条目使用真实 Shopify 内容及逐字段语言标记。Blog 显示实际发布日期和首个非空标签；
Guide 可在桌面显示不重复名称/栏目名称的真实辅助标签，手机隐藏，无标签不占位。
列表末尾显示实际条目数量与同语言另一栏目入口；空态保持栏目 H1 和可读说明。
两行摘要仅为视觉截断，初始 HTML 保留原始文字与真实链接。尺寸以局部 CSS 为准；
全站 Header/Footer 和其他内容页排版沿用各自现行规则。

Blog / Crystal Guide 详情和 About 根页/子页共用最大 50rem（约 800px）的实际阅读宽度，
容器先扣页面两侧留白再限制最大宽度，不在内部重复扣横向 padding 或叠加更窄的正文限制。
标题、作者信息、语言提示与正文左边缘对齐；About 简介可保留较短行宽。640px 及以下
两侧各留约 20px。保留各自正文的字体、行高与纵向节奏，长文自然重排。

About 导航后直接接左对齐正文。有子页时 root 第一项，当前项用下划线和 aria-current；
无子页不显示 tabs。手机可横向滚动，建议最多 5 项，过多时调整结构。仅明确且不重复
的 summary 作导语。Footer 服务链接与法律链接分组；顾客界面不暴露字段名或发布开关。

## 列表与购买交互

首页精选、Shop、分类、Collection 详情、搜索和 PDP 推荐共用商品网格与卡片，两种公开
语言使用相同列数：900px 及以上为四列，320px 至不足 900px 为两列，低于 320px 为
单列。商品网格断点独立于 Header 导航。只有一件商品时仍占一个格子，最后一行不足时
自然留空，不扩展卡片或补假商品。精选与推荐数量及选品规则见
[交易规格](COMMERCE_SPEC.md#选款筛选与卡片)。
760px 及以下商品列表区域两侧各留 16px、列间距 12px；标题约 15–16px，状态与价格
分行，商品名、币种、价格范围和变体完整换行。图片与无图占位共用正方形比例，响应式
sizes 随列数变化；具体尺寸以局部 CSS 为准。
较宽屏幕的价格与状态也允许换行，确保四列中的真实价格范围完整显示。

目录共用 sticky 筛选条：可购买、颜色多选、排序、结果数和可移除标签。选择立即生效，
更新时显示进度；清除条件保留排序，区分空目录和零结果。颜色显示真实文本，空值有说明。
使用原生 details 和 GET 链接，保留无 JS 操作，支持 Escape/外部点击及焦点恢复。
手机工具分两行，面板限制宽高。商业事实见 [交易规格](COMMERCE_SPEC.md#选款筛选与卡片)。

商品详情桌面双列，媒体在商品区 sticky，推荐前释放；手机单列，不 sticky。
缩略图单行横向滚动，不因图片多而换行。信息与购买操作共用页面留白，选款同步图片、
价格、数量和动作。加购为主按钮，Buy now 为次按钮；政策摘要靠近操作。
更新、需选款、售罄分别说明。Bag 小屏图片不挤压数量器，无图占位不继承详情页高度。

不使用素材文件名、假评论、空星级、倒计时、虚构低库存或羞辱性劝购文案。
营销弹窗不得遮挡首次任务，须容易关闭。

## 图片与无障碍

商品图须真实，独件对应交付物，标准品披露天然差异。生成图只用于明确的概念/编辑
内容，不伪装商品、客户、专家、来源、工艺或认证。图片有稳定尺寸、响应式 sizes 和
有意义的 alt；装饰图 alt 为空。Hero 和详情主图优先加载，其他媒体按需加载。

目标为 [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)，未经验证不得宣称符合：

- 语义 HTML、skip link、landmark、单一 H1、合理标题层级，原生控件优先。
- 键盘与焦点可见，菜单管理焦点，主要按钮和 Bag 文字按钮至少 44px。
- 控件有 label 和关联错误；加载、空态和错误易理解，故障有重试。
- 检查对比、200% zoom/reflow、读屏和 reduced motion；页面无横向溢出或 Header 遮挡。
- 不劫持滚动、自动有声播放或用动效延迟反馈。

组件按需要增长，不预建 UI kit。设备与支付验收见 [发布手册](LAUNCH_RUNBOOK.md)。
